# 货币金融学 · 利率传导诊断台

把《货币金融学》"利率"这一章的课程口径，做成一个**能用、能算、能验**的交互诊断工具。

**在线演示（手机可直接扫码打开）**：https://juice-butterfly.github.io/monetary-finance-rates/

> 这是一个「知识底座 + 交互应用」的双件套：
> `SKILL.md` + `references/` 是**知识底座**（这门课怎么讲利率）；
> `docs/index.html` 是**交互应用**（把知识用起来）。

## 一分钟看懂它在干什么

拖几根滑块，它会告诉你：

- **利率传导链**卡在哪一环（政策利率 → DR007 → LPR → 贷款 → 债券）；
- **四条课程规则**是否命中（息差约束、政策端实际利率近零、中美利差倒挂、曲线偏平）；
- **九个派生指标**（政策端/信贷端/债券端/短端债券四把尺子量实际利率、LPR 期限加点、期限利差、两个口径的中美利差、净息差）；
- **五张图**（利率走廊、中美利率对照、中美利差、收益率曲线、利率变动与债券回报率）；
- **五段式解读**（现象 / 理论 / 机制 / 含义 / 局限），由大模型生成；
- 以及最关键的一条：**AI 说的每个数字都能回溯到事实包**。

## 这个项目真正想解决的问题

大模型解读金融现象，最容易出的问题是**编数字**。

所以这里没有让 AI 从零写分析，而是分了三层：

| 层 | 谁在做 | 干什么 |
|---|---|---|
| **代码层** | JavaScript | 九个参数进来，确定性算出全部指标、命中全部规则。**数字不经过 AI** |
| **AI 层** | GLM-4-Flash | **只负责组织语言**，把算好的事实包写成五段话 |
| **校验层** | JavaScript | AI 输出里的每个数字，回到事实包里逐个核对；核对不上的当场标红 |

模型被硬约束"只能使用事实包中给出的数值"。校验层再把这句话变成**可执行的检查**——
所以你能看到页面底部那行「校验通过：输出中出现的全部数值均可追溯至事实包（共核对 N 处数字）」。

**把"你信不信我"变成"你自己验"。**

## 几个实现上的坑（留给后来人）

- **校验层要用数值归一化，不能做字符串精确匹配**。否则事实包里的 `3.875` 会被拆成 `4`/`3.9`/`3.88` 而漏掉自身，`1.50` 与 `1.5` 也会被判成不相等，产生大面积误报。
- **`DR007` 这类字符串里的 `007` 会被数字正则误抓**，需要 `(?<![A-Za-z0-9])` 这样的边界保护。
- **智谱的 CORS 是「回显 Origin」，不是只给 `null`**：实测 `file://`（Origin 为 `null`）和 `https://xxx.github.io` 两种来源都能直连，浏览器不拦，**两种部署方式都不需要本地转发**。这条是实测结论，别再凭猜测加代理。
- **测响应式别用 `--window-size=390`**：headless 浏览器有最小窗口宽度（实测 489px），得到的是假结果。改响应式后用 CDP 的 `Emulation.setDeviceMetricsOverride` 覆盖真实视口。
- **真实的一次翻车，值得保留**：线上第一次调用时，模型违反"不得自行推算"的约束，用 `1.26% − 1.2%` 自己算"实际利率"，得 **−0.8%**（正确应为 0.06%），被校验层当场标红。
  根因不是 prompt 不够狠，而是**事实包只给了政策端/信贷端实际利率，缺债券端**——模型缺数就自己编。
  修法：① 补齐 `派生_债券端实际利率_1年/10年`；② 把约束改成可执行的动作——「缺数时改用文字描述，不要写出数字」。
  一句话：**光写"不许编数字"没用，得让它编不出来**。
- **用 `segno` 生成二维码有两个必踩的坑**：① 输出的 `<svg>` **没有 `viewBox`**，宽高写死成 `41`，CSS 拉伸完全失效、二维码会小得离谱——要手动把 `width/height` 换成 `viewBox`；② `border=0` 会**去掉静音区**，规范要求四周至少留 4 个模块宽的白边，少了容易扫不出来。生成后一定要用解码器回读验证，别靠肉眼。
- **Windows 上 `cv2.imread` 读不了中文路径**，会静默返回 `None`。用 `cv2.imdecode(np.fromfile(path, np.uint8), ...)` 绕。
