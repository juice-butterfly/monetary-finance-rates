# 货币金融学 · 利率传导诊断台

把《货币金融学》"利率"这一章的课程口径，做成一个**能用、能算、能验**的交互诊断工具。

**在线演示（手机可直接扫码打开）**：https://juice-butterfly.github.io/monetary-finance-rates/

> 这是一个「知识底座 + 交互应用」的双件套：
> `SKILL.md` + `references/` 是**知识底座**（这门课怎么讲利率）；
> `docs/index.html` 是**交互应用**（把知识用起来）。

---

## 一分钟看懂它在干什么

拖几根滑块，它会告诉你：

- **利率传导链**卡在哪一环（政策利率 → DR007 → LPR → 贷款 → 债券）；
- **四条课程规则**是否命中（息差约束、政策端实际利率近零、中美利差倒挂、曲线偏平）；
- **五个派生指标**（政策端/信贷端实际利率、期限利差、两个口径的中美利差、净息差）；
- **五张图**（利率走廊、中美利率对照、中美利差、收益率曲线、利率变动与债券回报率）；
- **五段式解读**（现象 / 理论 / 机制 / 含义 / 局限），由大模型生成；
- 以及最关键的一条：**AI 说的每个数字都能回溯到事实包**。

---

## 这个项目真正想解决的问题

大模型解读金融现象，最容易出的问题是**编数字**。

所以这里没有让 AI 从零写分析，而是分了三层：

| 层 | 谁在做 | 干什么 |
|---|---|---|
| **代码层** | JavaScript | 九个参数进来，确定性算出全部指标、命中全部规则。**数字不经过 AI** |
| **AI 层** | GLM-4-Flash | **只负责组织语言**，把算好的事实包写成五段话 |
| **校验层** | JavaScript | AI 输出里的每个数字，回到事实包里逐个核对；核对不上的当场标红 |

模型被硬约束"只能使用事实包中给出的数值"。校验层再把这句话变成**可执行的检查**——
所以你能看到页面底部那行「校验通过：输出中出现的全部数值均可追溯至事实包（共核对 N 处数字）」。

**把"你信不信我"变成"你自己验"。**

## 怎么用

### 只想看 → 直接打开线上地址，或扫 README 顶部的链接

### 想在自己电脑上跑
下载 `docs/index.html`，**双击**即可。单文件、零依赖、不联网也能看图和离线示例。

支持任何 OpenAI 兼容接口。

> 想换成自己本地的服务器/代理，只需改「接口地址 Base URL」一项。

## 几个实现上的坑（留给后来人）

- **校验层要用数值归一化，不能做字符串精确匹配**。否则事实包里的 `3.875` 会被拆成 `4`/`3.9`/`3.88` 而漏掉自身，`1.50` 与 `1.5` 也会被判成不相等，产生大面积误报。
- **`DR007` 这类字符串里的 `007` 会被数字正则误抓**，需要 `(?<![A-Za-z0-9])` 这样的边界保护。
- **`file://` 直连智谱是可行的**：接口返回 `Access-Control-Allow-Origin: null`，正好匹配本地文件的 origin，不需要本地转发。
- **测响应式别用 `--window-size=390`**：headless 浏览器有最小窗口宽度（实测 489px），得到的是假结果。用 iframe 套一个固定宽度才是真视口。
