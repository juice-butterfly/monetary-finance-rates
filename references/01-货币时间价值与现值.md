# 01 货币时间价值与现值

> 来源：**陈思翀《第三讲：什么是利率？》课件 p3–p8（2026 年 9 月）**
> 口径优先级：课件 > 教材

## 一、货币的时间价值

- 货币的时间价值是**金融学的基石之一**
- 任何资产的价值都取决于其现金流的**水平、时机和风险**
- 三条判断原则（其他条件相同时）：
  1. **越大的现金流越有利**
  2. **越早收到现金越好**
  3. **风险越小越好**

> 定义：今天的"钱"和未来的"钱"之间的价值差异，称为**货币的时间价值**。

## 二、课件例题：环湖开"霸王茶山"

| 项目 | 数值 |
|---|---|
| 投资成本 | 今天 1,000 元 |
| 投资收益 | 一年后 1,050 元 |
| 备选方案 | 存入银行，赚取利息（按 10% 计） |
| 备选方案一年后 | 1,000 × (1 + 0.10) = 1,100 元 |

> 课件原文写作 `1×(1+0.10)=1100`，**算式疑为笔误**，按上下文应为 1,000 × (1+0.10) = 1,100 元。
>
> **结论**：项目收益 1,050 元 < 存款收益 1,100 元 → 该投资不划算。这就是"必须用共同的价值衡量标准比较不同时点现金流"的含义。

## 三、时间轴

- 无法直接比较不同时间点的现金流（Cash Flow）
- **下标表示现金流的时间点**
- **时间 0 = 今天**；时间 1 = 第一个周期（年、月等）的**末尾**，依此类推

```
CF₀      CF₁      CF₂      CF₃
 |        |        |        |
 0        1        2        3      ← Interest rate: i
```

## 四、现值（PV）

**为什么要折现**：一年后的 1 元比今天的 1 元价值低——
因为今天的 1 元可以存入银行赚取利息，一年后增值到 `1×(1+i)` 元。

**现值计算公式**：

```
PV = CFₙ / (1 + i)ⁿ
```

- `PV` = 现值　`CFₙ` = 未来现金流　`i` = 利率　`n` = 期限
- `1/(1+i)ⁿ` 称为**贴现因子**（现值复利因子）

**与教材的关系**：《中国金融学》第三章第二节给出了同一套公式的展开（单利 / 复利 / 连续复利 / 终值复利因子），
可作补充（见 `10-教材案例与思考题.md` 的公式速查部分）。

## 五、分析用法

- 比较任何两个不同时点的方案，**先折现到同一时点**再比
- 判断"利率变化如何影响资产价值"→ 从 `PV = CFₙ/(1+i)ⁿ` 看：i 上升 → PV 下降（债券定价的基本方向）
- 讨论"降息对资产价格的影响"→ 贴现率下降 → 未来现金流现值上升

## 六、易错点

- **时间 1 是一期之末，不是另一天**
- 折现用的是**期间利率**，期数与利率的周期口径必须一致（年利率配年数）
- 课件例题的"存银行 1100"是按 10% 算的——引用时要说明这个隐含利率
