# 04 名义利率与实际利率 · 费雪方程

> 来源：**课件 p18–p19（陈思翀）** + **教材《中国金融学》第三章第一节（p67–p69）**
> 口径优先级：课件 > 教材

## 一、名义 vs 实际（课件定义）

- **名义（nominal）利率**：**不考虑**通货膨胀
- **实际（Real）利率**：根据物价水平的变化进行调整，因此**更准确地反映了借贷成本**
  - **预期实际利率**：根据**预期**的物价水平变化进行调整
  - **事后实际利率**：根据**实际**的物价水平变化进行调整

> 课件强调实际利率"更准确地反映借贷成本"——
> 这是判断"降息是否真正降低了融资成本"的判据。

## 二、费雪方程式（Fisher Equation）

**课件的表述**：描述名义利率、实际利率和通货膨胀率之间的关系。
名义利率可以看作是**实际利率和预期通货膨胀率的和**：

```
i ≈ r + πᵉ
```

**含义**：投资者要求的名义利率，不仅包括他们希望获得的**实际回报**，
还包括他们预期的**通货膨胀补偿**。

费雪方程式有助于理解：在通货膨胀环境下，如何调整投资回报以反映真实的购买力变化。

**教材的完整式与简化式**（《中国金融学》式 3-1、3-2）：

```
i = (1 + r)(1 + πᵉ) − 1      （完整式）
i = r + πᵉ                    （πᵉ 较小时简化）
```

教材例题：借出年利率 5%、期限 1 年的普通贷款，合理预期价格水平将上升 3%
→ 实际利率 `r = 5% − 3% = 2%`。

**费雪效应**（教材）：物价发生变动时，为维持实际利率的稳定，名义利率会不断发生变化。

## 四、利率的分类（教材表 3-1，补充）

| 分类标准 | 利率种类 |
|---|---|
| 是否考虑物价变动因素 | 名义利率 / 实际利率 |
| 起息日的时点 | 即期利率 / 远期利率 |
| 借贷期限的长短 | 短期利率 / 长期利率 |
| 借贷期内利率是否调整 | 固定利率 / 浮动利率 |
| 计算利息的时间周期 | 年利率 / 月利率 / 日利率 |

要点：
- **即期利率**——债券票面所标明的利息收益、或购买债券时的折价收益，与债券当前价格的比率
- **远期利率**——隐含在给定即期利率中、从未来某一时点到另一时点的利率；
  反映市场对未来利率走势的预期，是中央银行制定和执行货币政策的重要参考工具
- **短期 / 长期**——短期指融资期限在一年（含）以内；长期利率因不确定因素增多，一般**高于**短期

## 五、其他核心概念（教材 p66–p67）

| 概念 | 定义 |
|---|---|
| 货币的时间价值 | 同等金额的货币，其现在的价值要大于其未来的价值 |
| 利息 | 借贷关系中资金借入方支付给资金贷出方的报酬 |
| 利率 | 一定时间内支付的利息总额与借贷本金总额的比率 |
| 无风险利率 | 将资金投资于无风险资产得到的利息率；**短期国债收益率**是天然的无风险利率 |

**利息的来源（马克思口径，教材特有）**：
利息实质是借贷资本家瓜分的、由雇佣工人在生产过程中创造的剩余价值。

## 六、分析用法

- 讨论"降息有没有用"→ 先算**实际利率**，看名义利率下降是否被通胀预期抵消
- 讨论"实际利率算不算高"→ 必须区分**事前 / 事后**口径，并标明用的是 CPI 还是核心 CPI
- 讨论"美债名义利率高不高"→ 扣掉美国通胀预期才是实际利率，才能跨经济体比较

## 七、易错点

- 实际利率 ≠ 名义利率 − 当期 CPI；严格应用**预期**通胀率（事前口径）
- "无风险利率"锚定在**短期国债收益率**，不是政策利率
- 跨中美比较利率时，必须说明是名义还是实际、什么口径
