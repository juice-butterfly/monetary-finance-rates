# 02 中国利率体系与利率市场化

> 来源：《中国金融学》第三章第一节第三、四目
> 原书位置：p69–74　｜　口径来源：课件 + 《中国金融学》

## 一、中国利率体系框架（原书图 3-1）

三层结构：

```
中央银行政策利率（OMO 7 天逆回购利率为核心）
            ↓
市场基准利率（DR ｜ LPR ｜ 国债收益率）
            ↓
市场利率（货币市场 ｜ 信贷市场 ｜ 债券市场）
```

## 二、中央银行政策利率

**定义**：中央银行为体现货币政策意图，面向金融机构投放或回笼流动性，
进一步影响同业拆借和存贷款利率的利率工具。

**利率走廊机制**（原书图 3-2）：

| 构件 | 指标 | 角色 |
|---|---|---|
| 上限 | 7 天期常备借贷便利（SLF）利率 | 走廊上限 |
| 中枢 | 公开市场操作 7 天期逆回购（OMO）利率 | 走廊中枢 |
| 下限 | 超额准备金存款利率 | 走廊下限 |

**调控对象**：存款类金融机构 7 天期质押式回购利率（DR007）被约束在利率走廊之中。
短期市场利率围绕 OMO 利率上下波动，波动范围受走廊上下限约束。

> ⭐ **2024 年以来，中国人民银行明确了以公开市场 7 天期回购操作利率为主要政策利率。**

## 三、市场基准利率

**定义**：金融市场上具有普遍参照作用的利率，是确定其他利率水平或金融资产价格的参考标准；
是利率市场化机制形成的前提条件和核心内容。

**选取标准（六个性）**：可靠性、稳健性、高频性、易得性、代表性、传导性。

| 基准利率 | 对应市场 | 要点 |
|---|---|---|
| **Shibor**（上海银行间同业拆放利率）| 货币市场 | 央行着力培育的市场基准利率；由信用等级较高的银行组成报价团自主报价、算术平均确定；品种含隔夜、1 周、2 周、1 个月、3 个月、6 个月、9 个月、1 年 |
| **DR**（存款类金融机构间债券回购利率）| 货币市场 | 2020 年《参与国际基准利率改革和健全中国基准利率体系》白皮书提出将其打造为货币政策调控与金融市场定价的关键参考指标；**未来中国基准利率体系的核心** |
| **LPR**（贷款市场报价利率）| 信贷市场 | 报价行自主报价，约束和指导非报价行贷款投放利率；含 1 年期、5 年及以上两个品种 |
| **国债收益率** | 债券市场 | 具无风险、参与主体多元化、流动性高、反映市场供求关系和预期变化等特征 |

**央行选择 DR 作为基准利率的六条理由**（论述素材）：
1. 存款类金融机构之间交易形成，有效剔除交易参与者信用资质干扰
2. 以国债、政策性金融债等风险权重为 0 的债券为抵押品，具无风险利率特征
3. 真实成交利率，可靠性强、不易被操纵
4. 交易活跃，全面、透明、易得，价格代表性强
5. 被认为是利率走廊的潜在目标中枢
6. 作为货币市场短端利率，是观察货币政策的风向标；短端利率可作"基准的基准"传导至中长端

**LPR 改革（2019 年 8 月）**：货币政策至信贷市场的传导路径由
```
贷款基准利率 → 贷款利率
```
转变为
```
货币政策工具利率 → LPR → 贷款利率
```
> 👉 这是解释"政策利率变动如何影响实体融资成本"的关键制度背景。

**当前局限**：DR 在回购市场之外尚无影响力，货币市场、浮息债券市场等金融产品的定价依然主要以 Shibor 为基础。

## 四、市场利率

由金融市场上供求关系决定的利率；自由竞争使货币资金供求趋于均衡时，市场利率即均衡利率。

- **货币市场利率**：回购利率（质押式 / 买断式）+ 拆借利率（Shibor / IBO / Chibor）
- **信贷市场利率**：存款利率（活期 / 定期）+ 贷款利率
  - 贷款利率受贷款品种、用途、担保方式影响：信用贷款 > 保证类 > 抵押 / 质押类
- **债券市场利率**：利率债（国债、政策性金融债、地方政府债）以招标发行为主；
  信用债（企业债、公司债、短融、中票等）以簿记建档发行为主；以国债收益率 + 信用利差为基准

**市场利率发挥作用的五个条件**：
1. 完全竞争的市场经济体系
2. 自主决策的微观经济主体
3. 充分传播的市场经济信息
4. 科学合理的利率弹性（其他经济变量对利率变化的敏感程度）
5. 健全完善的金融市场体系

## 五、利率管制与利率市场化

- **利率管制**：国家将资金利率调整到高于或低于市场均衡水平的政策措施；分单项管制与多项管制
- **利率市场化**：通过市场和价值规律机制，由供求关系决定利率的运行机制
- **理论基础**：金融抑制理论 + 金融深化理论
- **中国的改革步骤**：先外币后本币；先贷款后存款；先大额长期存款后小额短期存款
- **现阶段成效**：推进 LPR 改革 + 建立存款利率市场化调整机制；
  督促金融机构坚持风险定价原则、理顺贷款利率与国债收益率等市场利率之间的关系；
  规范存款利率定价行为，防范破坏市场竞争秩序的不合理定价

## 六、分析用法 ★

分析"政策利率变动为什么没传导到实体"时，按这条链**逐环检查**：

| 环 | 检查什么 | 断裂时的表现 |
|---|---|---|
| 1 | 政策利率（OMO 7 天逆回购）动没动 | 政策端按兵不动 → 下游缺乏定价基础 |
| 2 | DR007 是否在走廊内、是否贴近政策利率 | 走廊失效 / 资金面偏离 |
| 3 | LPR 报价有没有跟进 | 报价行加点未压缩 → 传导停在报价端 |
| 4 | 贷款利率（加权平均）有没有下降 | 实体融资成本粘性 |
| 5 | 债券收益率与政策利率的关系是否理顺 | 两条定价线脱节 |

**任一环断裂，就是传导受阻的位置——这正是分析的重点，也是最能出彩的地方。**
