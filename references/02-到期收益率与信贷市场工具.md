# 02 到期收益率与信贷市场工具

> 来源：**陈思翀《第三讲：什么是利率？》课件 p8–p14（2026 年 9 月）**
> 口径优先级：课件 > 教材

## 一、到期收益率（YTM）——课件的利率定义

**定义**：到期收益率（Yield to Maturity, YTM）是一种利率指标，
它是**使债务性金融工具未来现金流的现值之和恰好等于其当前市场价格的贴现率**，
即该金融工具的**内部收益率（Internal Rate of Return, IRR）**。

> 👉 这是课件对"什么是利率"的核心回答：**利率 = 让现金流现值等于价格的贴现率**。

## 二、四类信贷市场工具的利率

### （一）简单贷款（Simple Loan）

- 本金在到期日一次性偿还，期间不支付任何现金流
- 到期收益率：

```
P = FV / (1 + i)ⁿ      →      i = (FV / P)^(1/n) − 1
```

- 典型例子：商业银行向企业发放的一年期贷款（n = 1，此时 `i = (FV−P)/P`）

### （二）固定付款贷款（Fixed Payment Loan）

- 分期等额偿还本息（如房贷、车贷）
- 每期还款额的现值之和 = 贷款金额

### （三）付息债券（Coupon Bond）

- 定期支付息票利息，到期日偿还面值（本金）；在中长期债券中最常见
- 到期收益率由下式决定：

```
P = Σ [C / (1+i)ᵗ] + F / (1+i)ⁿ
```

- 现金流结构上，付息债券**可看作一组零息票债券的组合**（每一笔息票支付、到期面值偿还，均视为一张独立零息票债券）

### （四）折价债券 / 零息票债券（Discount Bond / Zero-coupon Bond）

- 以**低于面值**的价格发行、**不支付利息**、到期日按面值偿还本金
- 期限 n 年：`P = F / (1+i)ⁿ`，即 `i = (F/P)^(1/n) − 1`（F 为面值，P 为价格）
- 期限 n = 1 时简化为：`i = (F − P) / P`

**零息票债券的地位**（课件 p12）：
- 是"在特定日期偿付一元钱或一个单位商品的承诺"
- 收益率只是报价的一种方便形式；付息债券在实践中更常见
- **其他所有折价债券和付息债券，都看作一组零息票债券的组合来定价**

## 三、付息债券的三条观察（课件 p14）

1. 当附息债券**以面值定价**时，到期收益率**等于**票面利率
2. 附息债券的**价格与到期收益率呈负相关**
3. 当债券价格**低于**面值时，到期收益率**高于**票面利率

**课件表**：票面利率 10% 的 10 年期付息债券（面值 1,000 元）

| 债券价格（元） | 到期收益率（YTM） |
|---|---|
| 1,200 | 7.1% |
| 1,100 | 8.5% |
| 1,000 | 10.0% |
| 900 | 11.8% |
| 800 | 13.8% |

> 与教材《中国金融学》表 3-2 同源（教材用 80/90/100/110/120 的面值 100 元版本，课件用 800–1200 的面值 1000 元版本），**两处数值可互相印证**。

## 四、分析用法

| 要分析的问题 | 用哪类工具 |
|---|---|
| 短期贷款利率怎么算 | 简单贷款 |
| 房贷 / 车贷的实际成本 | 固定付款贷款 |
| 国债收益率与价格的关系 | 付息债券 |
| 短期国债贴现发行 | 折价债券（`i = (F−P)/P`）|
| 为什么要用 YTM 而不是票面利率比较债券 | YTM 是 IRR，剔除了价格因素，可跨债券比较 |

**关键判断**：讨论"债券利率"时，**默认指 YTM**（到期收益率），不是票面利率、不是当期收益率。
三者只有在按面值发行时才相等。

## 五、易错点

- YTM ≠ 票面利率 ≠ 当期收益率；只有按面值定价时才三者相等
- YTM 假设持有至到期且期间现金流按 YTM 再投资（**再投资风险**，课件未展开）
- 折价债券的"零息"指期间不付息，**不是说收益为零**——收益全部来自价差
