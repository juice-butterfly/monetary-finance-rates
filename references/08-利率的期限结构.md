# 05 利率的期限结构

> 来源：《中国金融学》第三章第四节
> 原书位置：p91–93　｜　口径来源：课件 + 《中国金融学》

## 一、定义与两个待解释现象

**利率的期限结构**：相同风险水平的金融工具，不同利率水平之间的关系，反映期限长短对其收益率的影响。

教材指出**两个特别值得注意的现象**：
1. 不同期限金融工具的利率往往是**同方向波动**的
2. 较长期限金融工具的利率**通常高于**较短期限的金融工具

三种解释 → 三个经典理论：**市场预期理论、市场分割理论、流动性偏好理论**。

## 二、市场预期理论

**四条假设**：
1. 整个资本市场是统一的，不同期限的金融工具之间具有**完全的替代性**
2. 投资者对不同期限的金融工具没有任何特殊的偏好，最终目标是利润最大化
3. 交易和持有金融工具没有成本，投资者能无成本地替换金融工具
4. 绝大多数投资者都可以准确预期未来利率，并据此作出合理的投资选择

**核心命题**：一次性长期投资的预期收益 = 多次、连续、等量短期投资的预期收益
→ **长期债券利率是期限内预期短期利率的平均值**

公式：`R_nt = (R₁ + Rᵉ₂ + … + Rᵉ_{n-1}) / n`　(3-18)

**曲线形态推断**：

| 预期 | 收益率曲线 |
|---|---|
| 未来每年短期利率相同 | 水平线 |
| 未来短期利率预期上升 | 向右上倾斜 |
| 未来短期利率预期下降 | 向右下倾斜 |

- ✅ 优势：把不同期限工具当作密切联系的统一体，**合理解释了不同期限利率的同向波动**
- ❌ 短板：**无法解释收益率曲线向右上倾斜**的现象，无法解释为什么长期利率会高于短期利率

## 三、市场分割理论

**核心主张**：批判市场预期理论的"完全替代"假设——各种期限的金融工具之间**根本没有替代性**，
它们的市场彼此独立、相互分割，**每种金融工具的利率由自身供求状况决定**。

**造成市场分割的五个原因**：
1. 投资者可能对某种期限的金融工具有特殊偏好
2. 投资者无法了解足够的信息，仅关注某些金融工具
3. 不同性质的借款人通常仅关注某种期限的金融工具
4. 一些机构投资者的负债结构决定了其投资期限的长短
5. 市场中缺少易于销售的统一的金融工具

- ✅ 优势：**直接解释了收益率曲线一般向右上倾斜**——人们通常更愿意持有短期工具，故短期利率相对较低
- ❌ 短板：将不同期限市场看成分割的，**无法解释不同期限金融工具利率通常同向波动**的现象

## 四、流动性偏好理论（期限结构语境）

**核心主张**：从投资者的流动性偏好角度解释短期与长期利率的差异来源。
短期金融工具的流动性比长期高——因为期限较短，**价格波动风险小于长期工具**；
风险规避者更偏好高流动性的短期工具，导致其利率低于长期工具。

确定远期利率时，不仅要考虑**预期信息**，还要考虑因风险因素引起的**流动性偏好**。

**修正公式**（在市场预期理论基础上加流动性溢价）：
`R_nt = (R₁ + Rᵉ₂ + … + Rᵉ_{n-1}) / n + l_nt`　(3-19)

- `l_nt` = t 时刻 n 期债券的**流动性（期限）溢价**

**结论**：大部分投资者偏好持有短期工具，为激励其持有长期工具，需支付流动性补偿；
**长期利率 = 预期的短期利率 + 流动性补偿**。

- ✅ 优势：描绘收益率曲线形状时，**比市场预期理论更合理、更一致**
- ❌ 短板：假设投资者总偏好期限较短的工具，但现实中**寿险公司、养老基金**等机构投资者
  往往更偏好长期工具（长期工具的收益期限与其资金期限更匹配）

## 五、三理论对照速查

| 理论 | 关键假设 | 能解释"同向波动" | 能解释"通常上倾" |
|---|---|---|---|
| 市场预期理论 | 完全替代、无期限偏好 | ✅ | ❌ |
| 市场分割理论 | 各期限市场彼此独立 | ❌ | ✅ |
| 流动性偏好理论 | 短期流动性更高 + 期限溢价 | ✅ | ✅ |

## 六、教材的总评

> 上述三种理论都在一定程度上说明了利率期限结构的存在，
> 但由于假设条件的局限性，**它们都不能完美地解释收益率现象**。
> 只有充分考虑理论背后的假设后，才能利用这些理论获得更加可信的分析结果。

## 七、分析用法

| 要分析的现象 | 用哪个理论 |
|---|---|
| 曲线整体上移/下移（同向波动）| 市场预期理论（预期短期利率变了）|
| 曲线形状为何通常是斜向上的 | 市场分割理论 或 流动性偏好理论 |
| **曲线倒挂**（长期低于短期）| 流动性偏好理论——预期未来短期利率大幅下降，且降幅超过流动性溢价 |
| 曲线变平 / 变陡 | 拆成"预期变化" + "期限溢价变化"两部分分别说 |
| 判断市场对未来政策路径的预期 | 市场预期理论（但要说明忽略了期限溢价，结论偏激进）|

> ⚠️ 术语提醒：本教材在**期限结构**语境下称"市场预期理论"；
> 若在货币需求语境下出现"流动性偏好理论"，那是凯恩斯的货币需求理论，**不要混用**。
